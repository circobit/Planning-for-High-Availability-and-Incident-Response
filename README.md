# 🛡️ Planning for High Availability and Incident Response

> This repository contains structured content and hands-on exercises from the **Planning for High Availability and Incident Response** course, part of the [Site Reliability Engineer Nanodegree](https://www.udacity.com/course/site-reliability-engineer-nanodegree--nd1331) by Udacity.

---

## 📖 Overview

This course teaches foundational skills for designing highly available systems and implementing effective incident response strategies. It includes labs and guided exercises covering:

- Defining SLIs, SLOs, and SLAs
- Creating disaster recovery (DR) plans
- Deploying services and monitoring infrastructure with Prometheus
- Managing PostgreSQL databases in AWS using RDS and Terraform
